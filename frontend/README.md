# ImportOps Frontend

Aplicación React + Vite.

## Configuración

Copiar `.env.example` a `.env` y ajustar las variables de API. Las variables `VITE_` se incorporan al bundle público: **no colocar secretos**.

```powershell
npm install
npm run build
```

Revisar el origen de la API y las reglas CORS antes de publicar en Azure Static Web Apps.
