# V11.3 - Fase 4.2 - Tareas por etapa

Nueva opción: `Configuración > Tareas por etapa`.

Permite:
- filtrar por etapa, estado y búsqueda;
- crear y editar plantillas;
- configurar obligatoriedad, plazo y orden;
- activar/desactivar;
- eliminar solo si nunca generó tareas;
- mostrar el número de tareas históricas generadas.

Las tareas automáticas siguen asignándose al responsable de la operación.
